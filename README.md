# CityScape Slider

Um slider interativo desenvolvido com HTML, CSS e JavaScript puro, apresentando destinos turísticos em destaque com animações suaves e navegação por thumbnails.

## 🚀 Demonstração
https://city-scape-slider.vercel.app/

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3 (Animations, Flexbox, Grid, Media Queries)
- JavaScript (DOM manipulation)

## ✨ Funcionalidades

- Navegação por botões (Next / Back)
- Thumbnails interativas
- Animações personalizadas com CSS
- Transições suaves entre slides
- Layout responsivo para desktop e mobile

## 📱 Responsividade

O projeto foi adaptado para diferentes tamanhos de tela utilizando media queries, garantindo boa experiência tanto em desktop quanto em dispositivos móveis.

## 🎯 Objetivo do Projeto

Praticar manipulação de DOM, animações CSS e construção de componentes UI modernos sem uso de frameworks.
